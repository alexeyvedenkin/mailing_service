### Функциональные возможности проекта:

#### 1. Настроены модели для создания сообщений, адресатов и рассылок
#### 2. Настроены модели для создания пользователей и попыток отправки рассылок
#### 3. Настроены контроллеры, маршруты и шаблоны для работы с моделями в парадигме CRUD
#### 4. Созданы формы для ввода данных с использованием валидации
#### 5. Реализованы кастомные команды для создания администратора, управления созданием пользователей, управления отправкой рассылок
#### 6. Реализована система регистрации и аутентификации пользователей
#### 7. Пользователи имеют возможность зарегистрироваться на сайте, подтвердив свой email
#### 8. Реализована функция входа и выхода из системы.
#### 9. Настроен сбор и отображение информации о количестве успешных/неуспешных попыток рассылок пользователя и количестве отправленных сообщений
#### 10. Настроены права доступа для пользователей и менеджеров
#### 11. Настроено серверное и клиентское кеширование для повышения производительности
